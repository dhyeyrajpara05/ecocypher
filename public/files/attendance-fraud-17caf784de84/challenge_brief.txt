THE ATTENDANCE FRAUD
Difficulty: Level 1–2 (Easy)
Category: Python / Pandas / Data Cleaning

attendance records to make certain students eligible for examinations.

- attendance_records.csv: the official attendance register
- classroom_entry_logs.csv: independent entry-gate scan records

The files contain mixed date formats, repeated gate scans and rejected scans.
Use Python to clean and reconcile the records. Identify the student whose
official attendance was artificially inflated.

Submit the student's ID in this format:
SHARK{STUDENT_ID}

Do not assume that every row represents a separate attendance. Follow the
policy and use only scheduled class IDs.
